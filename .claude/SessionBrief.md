## 用户答疑与重大架构升级交付

### 1. 深度解析：为什么打包的 `kof97pls.zip` 只有 1.36MB？整个游戏真的只有 2MB 吗？
- **街机 Neo-Geo / MAME / WinKawaks 经典「主包 / 克隆补丁包」(Parent / Clone ROM) 架构**：
  - 真正的游戏大本体是 **Parent ROM (`kof97.zip`)**，大小压缩后约 **29.2MB**，解压后超过 **55MB**，位于 `C:\Program Files (x86)\KOF97\roms\kof97.ZIP`。
  - 其中：
    - `KOF97_C1.ROM` ~ `KOF97_C6.ROM`（6颗共 **40MB**）：包含全量 327,680 个角色动作与特效图形瓦片（Sprites）；
    - `KOF97_V1.ROM` ~ `KOF97_V3.ROM`（3颗共 **12MB**）：包含全量角色语音与 ADPCM 音效；
    - `KOF97_M1.ROM`（128KB）：Z80 声音驱动 CPU 程序；
    - `neo-geo.rom` 等 BIOS 固件。
  - **`kof97pls.zip`（拳皇97 风云再起）是 Clone ROM（魔改克隆集）**：
    - 街机模拟器标准规范中，克隆版**不需要也不允许重复存储未修改的数十兆图形与音频文件**，仅需包含被修改的 CPU 核心代码！
    - `kof97pls.zip` 仅包含 3 个修改过的文件：
      - `232-p1p.bin`（1MB，68000 主逻辑程序）
      - `232-p2p.bin`（4MB，68000 角色状态与调色板数据）
      - `232-s1p.bin`（128KB，系统字符文字）
    - 经 ZIP 高压缩后物理体积正好为 **1.36MB**！
  - **模拟器加载机制**：
    - 在 `sandbox/WinKawaks.ini` 中配置了：
      - `RomPath1 = ..\output\roms`（优先加载我们魔改后的 1.36MB `kof97pls.zip`）
      - `RomPath2 = C:\Program Files (x86)\KOF97\roms`（自动透明引用原版 40MB 图形与 12MB 声音）
    - WinKawaks 在启动时自动将两者合并映射入内存，运行期游戏内存完整加载超 **55MB**，既节约存储，又保证运行速度。
